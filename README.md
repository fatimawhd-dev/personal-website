# Fatima Waheed — Portfolio

Personal portfolio for Fatima Waheed, Full Stack Developer.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis smooth scroll

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
npm start
```

## Content

Site copy, projects, and links live in `src/data/content.ts`.

- Project images: `public/projects/`
- Resume: `public/resume.pdf`
- Toolkit icons: `public/tech/`


## Deploy

The app is set up for [Vercel](https://vercel.com). Connect the repo there, or check a production build locally with `npm run build`.
